## 👋 Hey, I'm Abdul-ur-Rehman

I'm a test automation engineer who'd rather spend a day making a flaky test stable than ship a fix that might break again next week. I work at **Dubizzle Labs**, where I write Playwright tests, dig into why regressions fail, and build the tooling that helps teams see whether a release is actually healthy.

I care about the parts of quality work that don't get much applause: clear failure reports, reliable pipelines, and helping developers feel comfortable writing their own tests.

<br/>

## 🔭 What I'm up to lately

```text
🎭  Scaling Playwright + TypeScript suites across multiple products
📊  Building dashboards that turn raw CI results into something a manager can read in 30 seconds
🤖  Pairing with Claude Code and Cursor to write, refactor and review automation faster
🧱  Building a fullstack app on the side (React, Node, Express, MongoDB)
🧾  Experimenting with audit and data tooling outside of QA
```

<br/>

## 🧠 Things I believe about testing

> **A flaky test is a bug.** Fix it or delete it, never just re-run it.
>
> **Good failure messages** save more time than clever test code.
>
> **Shift left.** Developers who own their tests ship calmer releases.
>
> **AI is a great pair programmer** and a terrible substitute for thinking.
